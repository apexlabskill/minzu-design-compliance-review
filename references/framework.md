# 审查方法论 · 通用红线详表 · 正向替换词库

本文档是 `minzu-design-compliance-review` 的完整审查框架。做严肃审查时先读本文件，再按需加载对应民族的 `ethnic-data-01~06.md`。

---

## 一、审查方法论（完整版）

### 1.1 判定链路

```
输入 → ①内容类型 → ②涉及民族 → ③应用场景/产品 → ④民族禁忌表逐条比对 → ⑤12条通用红线交叉检查 → ⑥风险分级 → ⑦输出报告
```

### 1.2 内容类型处理差异

| 输入类型 | 审查重点 | 输出重点 |
|---|---|---|
| **设计图/成品图** | 画面元素（纹样、配色、人物、符号、载体）逐项识别 | 问题清单 + 改图建议（哪些元素删/换） |
| **设计文档/需求** | 场景、产品类目、元素清单、文案、命名、谐音 | 逐条合规判断 + 文案替换方案 |
| **提示词（生图/生视频）** | 每个 token：民族元素、图腾、配色、场景、载体、动作叙事 | 优化后的完整提示词（删除违规词、替换安全词、补充正向约束） |

### 1.3 民族识别提示

- 先看用户明说的民族；若未明说，从纹样/服饰/配色/符号反推（如：蓝白扎染→白族、蜡染蓝靛→苗族、红黑金虎纹→彝族、黑底五色花边→畲族凤凰装、七彩袖→土族、铜鼓→壮/布依、鼓楼→侗族、馕/小花帽→维吾尔/乌孜别克、白毡帽→柯尔克孜、鱼皮→赫哲、狍皮帽→鄂伦春、驯鹿→鄂温克）。
- 混搭多民族时，逐个民族单独审查，并额外检查"支系/纹样跨民族混淆"（如白族扎染 vs 苗族蜡染、土家白虎 vs 彝族黑虎、景颇长刀 vs 阿昌户撒刀）。

## 二、12 条通用红线详表

### 红线 1：伊斯兰猪酒红线（10 个信仰伊斯兰教的民族统一适用）

适用民族：回族、维吾尔族、哈萨克族、柯尔克孜族、塔吉克族（伊斯玛仪派）、乌孜别克族、东乡族、撒拉族、保安族、塔塔尔族。

| 检查项 | 规则 | 安全替代 |
|---|---|---|
| 猪/猪肉/猪内脏形象 | 任何产品禁止；部分民族语境连"猪"字都忌 | 牛、羊、骆驼、鸡、葡萄、石榴、牡丹 |
| 酒类图案 | 禁止 | 茶、奶茶、奶制品、果饮 |
| 自死动物、动物血 | 禁止 | — |
| 阿拉伯文/经文 | 不可当"异域装饰字体"随意变形；常见阿拉伯文多为《古兰经》经文 | 植物花卉纹、几何纹、卷草纹、拱门轮廓（不写真经文） |
| 清真寺/拱北/圣龛/邦克楼造型 | 不可印在鞋袜、拖鞋、烟灰缸、纸巾、脚垫等不洁载体；不可戏谑化 | 拱券、尖拱、几何星盘、砖雕纹 |
| 人物/动物立体雕像、写实画像 | 伊斯兰严禁偶像崇拜 | 几何纹、植物纹；动物纹需高度抽象化 |
| 女性形象 | 不可暴露、性感化；盖头配色有年龄分层（少女绿/婚后黑/老年白，保安族"少绿-婚黑-老白"） | 端庄、按年龄色表现盖头 |
| 清真食品标识 | 需经正规清真认证机构授权，不可自行标注 | — |

### 红线 2：宗教神圣符号不洁载体（现行有效，信仰尊重）

| 宗教体系 | 神圣符号 | 禁止载体 | 安全载体 |
|---|---|---|---|
| 藏传佛教 | 佛像、唐卡、六字真言、八吉祥（法轮/白海螺/宝伞/胜利幢/宝瓶/金鱼/吉祥结/莲花）、金刚杵、法轮、转经筒、雍仲卐、袈裟 | 袜子、内裤、内衣、床单、脚垫、地板贴、手机壳、T恤下摆、一次性用品 | 挂画、香卡、摆件、佛珠配饰、高端正经文创（上方/正面/独立展示位） |
| 南传佛教（傣/布朗/德昂） | 佛塔、佛像、菩提树、佛爷 | 鞋袜、内衣、食品包装、下身服饰 | 挂轴、香品、文创摆件 |
| 东巴教（纳西） | 东巴经书文字、神路图、东巴神像 | 喜庆/商业产品 | 学术展陈、博物馆 |
| 萨满教（蒙古/满/达斡尔/鄂温克/鄂伦春/赫哲/裕固等） | 神衣铜镜铜钮、神帽鹿角、索伦杆、玛路、人面天神 | 贴纸、盲盒、表情包、贴身用品 | 严肃文化展陈 |
| 东正教（俄罗斯族） | 十字架、圣母像、洋葱头教堂 | 袜子、内裤、纸巾、口罩、一次性用品 | 独立展示、正面上方 |

### 红线 3：色彩语义冲突矩阵（最易翻车）

| 色彩 | 把它当"丧/负面"的民族 | 把它当"尊贵/吉祥"的民族 |
|---|---|---|
| 白色 | 汉族（传统丧服主色） | 蒙古、藏、白族、朝鲜、满、普米、柯尔克孜、达斡尔等（圣洁/尊贵/驱魔） |
| 黑色 | 汉族、俄罗斯族（丧服/孝服） | 彝（黑彝贵族）、哈尼（生命保护色）、拉祜（尊贵）、佤（尚黑）、赫哲（贵重/天穹色）、土家（部分） |
| 明黄 | 汉族、满族、蒙古（历史帝王/贵族专用色） | —（现代无禁令但"帝王感"联想仍在） |
| 红色 | 汉族、多数民族（喜庆） | 京族（日常不穿红，红留给哈节礼服）、满族早期尚白贱红 |

**附加规则**：
- 藏经幡五色（蓝白红绿黄）有固定排列顺序，不可打乱；红黄为寺院高等级色，民居/日常消费品慎大面积满铺。
- 朝鲜五方色（红蓝黄白黑）对应方位五行，是有秩序符号系统，不可无逻辑堆色；Saekdong 七彩缎主要儿童周岁礼服用，成人正装不用。
- 土族七彩袖（红黄绿青蓝紫白）每条色有象征；黄色受藏传佛教影响属高等级色，不可用于下身/内衣。
- 维吾尔绿=神圣庄重（与伊斯兰、草原祖源相关），不可当"清新色"随便配；红=婚庆喜色（拜火教火神崇拜）。
- 哈萨克族忌讳黄色，视黄色象征病弱、灾祸、凶兆；婚庆与喜庆场合忌大面积黄色（区别于汉族"明黄=帝王尊贵"、藏传佛教"黄=高等级"两种语义，哈萨克族是"黄=不吉"）。

### 红线 5：祭祀/礼器纹样不可轻佻化

铜鼓（壮/布依/侗，含祭祀调/十二芒太阳纹）、鼓藏节（苗）、目瑙示栋（景颇，祭祀柱）、祖图（畲）、神路图（纳西）、跳丧鼓（土家）、羊皮鼓舞/铠甲舞（羌）、纳顿傩舞面具（土）、肥套傩面（毛南）、给羊子（普米）、镖牛（佤）、雅德根神衣（达斡尔）、萨满神衣（鄂温克/鄂伦春）、毕摩法器（彝）、摩批器物（哈尼）、释比法器（羌）、水书（水族占卜经书）等。

**通用规则**：祭祀纹样用于年节文创、博物馆展陈、非遗纪录片可以；**不可**印在搞笑周边、情趣用品、食品促销、潮玩盲盒、表情包；**不可**配合暴力/血腥/猎奇叙事。

### 红线 6：丧葬纹样与喜庆错位

- 瑶族红瑶：婚礼必盛装红衣银饰，丧事素色无花无红——不可错位。
- 土家台台花/猫脚迹：嫁妆专属纹样，不可用于商务男装等非嫁妆场景。
- 黎族大力神纹/船型屋纹：始祖/迁徙记忆符号，不可用于廉价婚庆红事。
- 羌族黑虎乡白头帕"万年孝"：孝帕，非喜庆装饰。
- 锡伯族墓堆红布幡/纸幡：丧葬礼制符号，不可挪作节日装饰。

### 红线 7：支系混淆

苗族（湘西/黔东南/川黔滇）、瑶族（红瑶/白裤瑶/盘瑶/蓝靛瑶等上百支系）、彝族（凉山/楚雄/毕节）、高山族（泰雅/赛夏/布农/排湾/鲁凯/达悟等）、羌族（黑虎/蒲溪/赤不苏）、门巴族（门隅/墨脱）、珞巴族（博嘎尔/崩尼/阿帕塔尼等）——**一个项目先锁定一个支系**，禁止拼盘式"通用民族风"。

### 红线 8：神圣方位/结构不可颠倒

- 蒙古包西炕=供佛方位（客人不可坐西炕）。
- 满族西墙=供奉祖宗板（忌挂衣物、贴年画、坐卧）。
- 景颇目瑙示栋：左雄牌太阳、右雌牌月亮，螺旋迁徙路，不可旋转/镜像/重排。
- 基诺太阳鼓：公鼓母鼓方位不可乱。
- 门巴巴尔霞帽：楔形缺口朝右眼上方，方向错即失真。
- 普米族百褶裙中间横线=祖先南迁路线，不可删改。

### 红线 9：已革除历史不可猎奇消费

- 佤族猎头历史（1958年已革除，立碑"人头不长谷，牛头也可敬神"）。
- 藏族天葬（《西藏自治区天葬管理暂行规定》禁止围观、拍照、传播渲染）。
- 独龙族纹面、黎族文身、泰雅纹面（成年礼/族群身份，非潮流装饰）。

### 红线 10：动物禁忌

| 动物 | 相关民族 | 规则 |
|---|---|---|
| 狗/犬 | 满族、锡伯族、畲族、瑶族（盘瓠）、东乡族 | 忌食狗肉、忌狗皮制品；盘瓠是始祖图腾不可萌宠化 |
| 熊 | 鄂伦春、鄂温克、达斡尔 | 是祖灵/神灵，不可食物化、丑化 |
| 猫头鹰 | 哈萨克 | 神圣鸟，羽毛辟邪，不可"拔毛"戏谑 |
| 天鹅 | 哈萨克 | 保护神，忌猎杀 |
| 鹰 | 塔吉克、哈萨克 | 图腾，不可画猎杀/食物 |
| 马/驴/骡（圆蹄） | 土族、裕固族、东乡族、柯尔克孜 | 忌食圆蹄牲畜；裕固族禁食尖嘴圆蹄动物 |
| 猫/蛇/狗/猪心 | 仫佬族 | 忌食猫肉、蛇肉，部分忌狗肉、猪心 |

### 红线 11：火崇拜禁忌

蒙古、彝、羌、鄂伦春、鄂温克、裕固、普米、达斡尔等敬火民族：火/火塘/火盆是神圣物（火神所在）。火焰符号**不可**用于垃圾桶、宠物用品、卫生耗材；**不可**配合踩踏、倾倒、吐痰、刀叉/铁器捅火、跨越火塘的叙事。

### 红线 12：数字/谐音/符号方向

- 俄罗斯族：忌"13"（不祥）、周五（耶稣受难）、黄色（背叛/不忠）。空钱包送人不吉。
- 京族：忌"焦"（同"礁"，怕触礁）、"油/游"（船上忌说，改"滑水"）。
- 藏族雍仲卐：藏传佛教右旋（顺时针），苯教左旋，方向错=用错教派；更不可与纳粹卐混淆。土家西兰卡普卍字纹保持右旋传统方向。

## 三、风险分级标准

| 等级 | 定义 | 处置 |
|---|---|---|
| 🔴 严重违规（红线） | 信仰核心（伊斯兰猪酒）、宗教神圣物印不洁载体、法律禁止项（天葬传播）、始祖图腾严重亵渎 | 必须修改，不可商用 |
| 🟠 高风险（文化冒犯） | 图腾卡通化、祭祀纹样轻佻化、神圣符号印贴身/下身 | 强烈建议修改 |
| 🟡 中风险（语义错位） | 色彩语义冲突、支系混淆、纹样错配、谐音踩雷、方位颠倒 | 建议修正 |
| 🟢 建议优化 | 非违规，可提升文化准确度与调性 | 可选 |

## 四、正向替换词库（优化提示词用）

### 4.1 神圣→世俗替换（宗教/图腾/祭祀 → 安全纹样）

| 违规/高风险元素 | 安全替代 |
|---|---|
| 佛像、唐卡、六字真言 | 雪山、格桑花、牦牛、藏式几何边纹、围裙条纹 |
| 清真寺穹顶、阿拉伯经文 | 拱券、尖拱、几何星盘、砖雕纹、巴旦木花、石榴花 |
| 五色经幡（派对拉花） | 色条（不印经文）、哈达意象、藏式边纹 |
| 铜鼓整面三界纹 | 太阳芒纹、几何晕圈做边饰 |
| 蝴蝶妈妈卡通 | 普通蝴蝶花卉纹、几何化刺绣化处理 |
| 盘瓠萌宠狗 | 凤凰装、彩带、山哈山林意象、龙犬首人身始祖形象（庄重） |
| 葫芦恶搞 | 圆润庄重葫芦 + 芦笙、拉手舞纹组合 |
| 虎写实血腥 | 抽象/几何化虎纹 |
| 蛙写实/惊恐 | 壮锦几何骨架中的蛙形纹、古拙圆鼓蹲姿 |
| 熊卡通 | 抽象熊纹、鹿、狍、花草纹 |
| 孔雀写实动物园 | 傣锦眼状斑孔雀羽纹、开屏舞蹈优雅曲线 |
| 太阳鼓玩具 | 鼓面太阳放射纹、鼓钉圆点平面图形 |
| 木鼓Q版 | 鼓面环形纹、公母鼓大小对比图形 |
| 铜镜/铜钮（萨满神衣） | 云卷纹、花草纹、几何纹 |
| 水书字符 | 象形笔画、螺旋三角结构抽象几何纹 |
| 东巴文乱拼 | 已释读吉祥字符（爱/福）+ 注明出处，或东巴画线条风 |
| 文字乱写（画绢/卷轴） | 简洁写意花鸟设色、无任何文字 |

### 4.2 色彩替换

| 场景 | 违规用法 | 安全用法 |
|---|---|---|
| 汉族红事 | 大面积素白 | 米白、牙白、月白、玉白暖调底 + 红金主色 |

## 五、审查措辞规范

- 使用"禁忌""文化风险""信仰尊重""文化联想""神圣性"等中性、尊重措辞。
- 区分"现行有效"（信仰/法律）与"历史礼制已废止"（明黄、五爪龙等 1912 年后无禁令）。
- 涉及【地域差异】【学界有争议】时如实标注，不武断下结论。
- 结论始终附带"重要项目建议咨询当地民族宗教部门或非遗传承人"。
- 严禁用于歧视、歪曲或商业贬损任何民族文化的用途。
