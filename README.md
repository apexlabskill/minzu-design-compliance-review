# 56 民族设计合规审查（民族/宗教禁忌红线审查）

一个用于审查**与 56 个民族（少数民族）文化相关**的设计图、设计文档、海报、包装、纹样、服装、LOGO、IP 形象、盲盒潮玩、文创以及 AI 生图/视频提示词的 Skill，帮助设计师避免触碰民族禁忌与宗教禁忌红线。

## 功能

- 内置 56 个民族完整的 **「场景/产品 → 禁用元素 → 文化原因 → 安全替代」** 禁忌表。
- 内置 **12 条跨民族通用红线**（伊斯兰猪酒红线、宗教神圣符号不洁载体、色彩语义冲突、始祖图腾不可卡通化、祭祀纹样不可轻佻化、丧葬纹样喜庆错位、支系混淆、神圣方位颠倒、已革除历史不可猎奇、动物禁忌、火崇拜禁忌、数字/谐音/符号方向）。
- 输出 **合规结论 + 问题清单（风险分级）+ 修改方案 + 优化后的提示词**。
- 风险分级：🔴 严重违规 / 🟠 高风险 / 🟡 中风险 / 🟢 建议优化。

## 安装

将整个 `minzu-design-compliance-review` 目录放入你的 Skills 目录（用户级 `~/.workbuddy/skills/` 或项目级 `{workspace}/.workbuddy/skills/`）即可。

## 使用方法

当用户上传或提交与少数民族文化相关的设计内容，并要求「审查 / 检查 / 避坑 / 合规 / 是否触犯禁忌 / 民族禁忌 / 宗教禁忌 / 改文案 / 优化提示词」时，自动触发本 Skill。

## 免责声明

- 审查依据均基于公开的权威文献（地方志、民族学文献、国家民委 neac.gov.cn、中国非遗网 ihchina.cn、中央统战部等），旨在帮助设计师避免无心之失。
- 各民族支系众多、地域差异大，具体项目请以当地民族文化实际情况为准。
